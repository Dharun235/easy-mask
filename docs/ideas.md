# Ideas

Possible future features, most useful first. Nothing here is promised.

- **Double-click app**: install without git, uv or a terminal.
- **Frame timeline**: see which frames have masks; click to jump.
- **Play with masks**: scrub the video to spot tracking drift.
- **Check these frames**: flag frames where tracking looks doubtful.
- **Text prompts**: type "wing" to pre-label every frame.
- **Measurements**: area, angle and speed per object over time.
- **Custom key points**: named points (tip, base, joint) per label.
- **Export video**: mp4 with masks and points drawn on.
- **More formats**: Pascal VOC export, COCO / YOLO import.
- **Usability tests**: watch new users try one task; fix where they get stuck.
